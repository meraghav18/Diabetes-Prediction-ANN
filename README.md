# 🩺 Diabetes Prediction using Artificial Neural Network (ANN)

## 📌 Project Overview

This project predicts whether a person is likely to have diabetes using an Artificial Neural Network (ANN) built with TensorFlow/Keras.

## 🚀 Features

- Diabetes Prediction using ANN
- Data Preprocessing
- Feature Scaling using StandardScaler
- Streamlit Web Application
- Trained Model (.keras)
- Saved Scaler (.pkl)

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pandas
- Scikit-learn
- Joblib

## 📂 Project Structure

```
Diabetes-Prediction-ANN/
│── app.py
│── ANN.ipynb
│── diabetes.csv
│── diabetes_model.keras
│── scaler.pkl
│── requirements.txt
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📊 Dataset

Pima Indians Diabetes Dataset
